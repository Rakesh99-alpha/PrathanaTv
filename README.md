# PrathanaTv - Christian Channel Website

A modern, responsive website for PrathanaTv Christian television channel, dedicated to spreading the Gospel of Jesus Christ and providing spiritual content to viewers worldwide.

## Features

- **Responsive Design**: Fully responsive layout that works seamlessly on desktop, tablet, and mobile devices
- **Hero Section**: Engaging landing page with call-to-action buttons
- **About Section**: Information about the channel's mission and values
- **Live Streaming**: Section for broadcasting live worship services and programs
- **Sermon Library**: Archive of recent sermons and teachings
- **Weekly Schedule**: Display of regular programs and service times
- **Prayer Requests**: Interactive form for viewers to submit prayer requests
- **Contact Section**: Multiple ways to get in touch with the channel
- **Social Media Integration**: Links to various social media platforms
- **Smooth Navigation**: Fixed navigation bar with smooth scrolling
- **Interactive Elements**: Engaging animations and hover effects

## Technologies Used

- HTML5
- CSS3 (with CSS Grid and Flexbox)
- Vanilla JavaScript
- Font Awesome Icons (CDN)

## File Structure

```
PrathanaTv/
├── index.html      # Main HTML file with all sections
├── styles.css      # CSS stylesheet with responsive design

└── README.md       # Project documentation
```

## Sections

1. **Navigation**: Fixed navigation bar with links to all sections
2. **Hero**: Welcome section with inspirational message and call-to-action
3. **About**: Channel mission, values, and purpose
4. **Live Stream**: Live broadcast section with viewer stats
5. **Sermons**: Recent sermon library with thumbnails
6. **Schedule**: Weekly program schedule
7. **Prayer Requests**: Form for submitting prayer requests
8. **Contact**: Contact information and contact form
9. **Footer**: Additional links and social media

## Getting Started

1. Clone the repository
2. Open `index.html` in a web browser
3. No build process or dependencies required!

## Customization

To customize the website for your channel:

1. **Colors**: Update CSS variables in `styles.css`:
   - `--primary-color`: Main brand color
   - `--secondary-color`: Accent color
   - `--dark-color`: Dark theme color

2. **Content**: Edit `index.html` to update:
   - Channel name and branding
   - About section text
   - Sermon titles and speakers
   - Schedule times and programs
   - Contact information

3. **Images**: Replace placeholder sections with actual images/videos
